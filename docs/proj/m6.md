> **本期原则**：
> - **双轨验收**：自动化单测（TS + Native + QuickJS + 无头渲染回归，含本地环回 HTTP 与磁盘原子写/重定位测试）守住确定性行为与既有像素基线；真窗口实机把玩（托盘驻留零显存、Explorer 重启自恢复、任务栏进度/缩略图按钮、SMTC 锁屏卡片、单实例热唤醒、网络下载与液态玻璃感知降级）供主人亲手验证。
> - **一口气做完**：按章节顺序推进，不设中途验收点。只有遇到本文件没定、又影响公开接口或范围的事才停下来问主人。
> - **不造假桩、严守边界**：系统 API 能做的不引第三方依赖（Win32 Shell / `ITaskbarList3` / WinRT SMTC ABI / WinHTTP / `SHGetKnownFolderPath`）；属 M7 的 Native 扩展 SDK 接口（`ctx.paths()` / `canton::fs` / `ctx.timers()` / `ctx.net()`）保留底层 C++ 复用结构但不在本期暴露 C ABI 壳；属 M8 的安装期文件关联与 URL 协议注册留待打包器落地。
> - **严守分层、物理剥离与命名规范**：`win32`、`d3d11` 只依赖 `core`；`CANTON_ENABLE_DEV` 只出现在构建接线与 `host/`；`@canton/kyant-glass` 只能导入 `@canton/framework` 公开出口；所有 `.cta` 参数、事件与槽位句柄统一采用小驼峰合法 JS 标识符（遵守 B3：2）。
> - **命名不带里程碑编号**：新增文件、夹具与测试按内容命名；进度、实测数据与决策记入文末“施工笔记”。

开工基线（M5 收口态，`1857c3f`）：`typecheck`、`typecheck:cta`、`verify:modifier-protocol`、`format:check`、`build:packages` 通过，`test:runtime`、`test:native`、`test:quickjs`、`test:render`（32/32，WARP 与硬件两档）、`verify:host`、`verify:live-hmr`、`verify:live-recovery` 全过。

## 0. 已定口径

- **公开导出落点与目录分层**：
  - **`@canton/framework`（主入口）**：
    - `assets` 补齐 `assets.exists(reference: string): Promise<boolean>`；
    - 启动载荷注入键 `LaunchRequestKey` 与只读类型 `LaunchRequest`；
    - `<App>` 新增可选回调 `:onSecondInstance="(request: LaunchRequest) => void"`；
    - `<Window>` 新增可选任务栏属性：`taskbarProgress`、`taskbarBadge`、`taskbarActions`；
    - 定时器框架封装：`useTimeout`、`useInterval`、`delay(ms, signal?)` 与 `TimerHandle` 类型。
  - **`@canton/framework/ui`**：
    - `GraphicsEnvironmentKey` 及只读类型 `GraphicsEnvironment`、`GraphicsTier`（与 `DensityKey` 并列）。
  - **`@canton/framework/shell`（新增公开子路径）**：
    - 托盘与双轨菜单组件：`<TrayIcon>`、`<SystemTrayMenu>`、`<CustomTrayMenu>`、`<MenuItem>`、`<MenuCheckbox>`、`<MenuRadio>`、`<MenuSeparator>`、`<SubMenu>`（默认槽句柄 `&menuHandle` 提供 `dismiss()`）；
    - 系统全局媒体控制组件：`<MediaSession>`；
    - Jump List 运行时函数：`setJumpList`、`clearJumpList` 及对应条目/分类类型。
  - **`@canton/framework/fs`（新增公开子路径）**：

    - 全异步文件与目录 I/O：`readText`、`readBytes`、`writeText`、`writeBytes`（写入支持 `{ atomic?: boolean }`，默认 `false`）、`exists`、`stat`、`readDir`、`mkdir`、`remove`、`rename`、`copy` 及结构化 `FsError`。
  - **`@canton/framework/net`（新增公开子路径）**：
    - `request`、`http`（`get`/`post`/`put`/`patch`/`delete`/`head`）、`downloadFile`、`NetError`、`NetErrorCode` 及相关选项/响应类型。
  - **`globalThis`（宿主启动期自动挂载）**：
    - `setTimeout`、`clearTimeout`、`setInterval`、`clearInterval`、`queueMicrotask`、`AbortController`、`AbortSignal`（定时器仅接受函数回调，禁止字符串代码求值）。
  - **包分层守卫**：`packages/framework/package.json` 新增 `./shell`、`./fs`、`./net` 出口，`tsconfig.json`、`scripts/build-internal-packages.ts` 与 `tests/runtime/package-layers.test.ts` 同步纳入检查，保持零循环导入。
- **App 级隐藏顶层 `HWND` 底座（ADR B1：5）**：
  - 将当前 `win32::MessageDispatcher` 的 `HWND_MESSAGE` 升级为（或配对维护）进程唯一的 **App 级隐藏顶层 `HWND`**（带 `WS_EX_TOOLWINDOW`、永不 `ShowWindow`、不入任务栏与 Alt-Tab、零 GPU 显存），统一承接：
    1. `<TrayIcon>` 的 `Shell_NotifyIconW` 消息与 `RegisterWindowMessageW(L"TaskbarCreated")` 广播重建；
    2. SMTC `ISystemMediaTransportControlsInterop::GetForWindow` 所需的真实顶层 `HWND`；
    3. 无可见业务窗口常驻时的 `WM_QUERYENDSESSION` / `WM_ENDSESSION`、`WM_FONTCHANGE`、`WM_SETTINGCHANGE`（监听系统透明效果/动画开关变更）以及跨线程唤醒。
  - 当全部 `<Window>` 关闭且 `<App :exitOnLastWindowClosed="false">` 托盘常驻时，销毁全部窗口 `d3d11::RenderTarget` / SwapChain，并保持空闲停表零显存占用。
- **系统托盘与双轨菜单（ADR B1：5）**：
  - `<TrayIcon>` 仅允许挂在 `<App>` 下（画区外），支持 `id?: string`、`guid?: string`、`icon?: string`（默认回退 `<App :icon>`）、`tooltip?: string`、`visible?: boolean`（默认 `true`）、`onClick`、`onDoubleClick`、`onContextMenu`。未显式传 `guid` 时按 AUMID + 托盘键稳定派生 `GUID`（UUIDv5 / SHA-256 截断），以保留 Win11 托盘区显隐偏好。
  - 同一 `<TrayIcon>` 内 `<SystemTrayMenu>`、`<CustomTrayMenu>` 与 `onContextMenu` 互斥，混写直接运行时报错：
    - **`<SystemTrayMenu>`**：纯 Win32 `HMENU` + `TrackPopupMenuEx`，自动执行 `SetForegroundWindow(appHwnd)` + 菜单关闭后 `PostMessage(appHwnd, WM_NULL, 0, 0)` 防僵尸菜单；支持 `<MenuItem>`（`label`/`enabled`/`onClick`）、`<MenuCheckbox>`（`label`/`checked`/`enabled`/`onChange`）、`<MenuRadio>`（`label`/`selected`/`enabled`/`onSelect`）、`<MenuSeparator>`、`<SubMenu>`（`label`/`enabled` 可嵌套）；全程零 GPU 显存；
    - **`<CustomTrayMenu>`**：内部托管无边框 `WS_EX_TOOLWINDOW` 置顶弹窗，建立独立画区作用域供放置任意自绘 Arrangable，默认槽交付 `&menuHandle`（`dismiss(): void`）；右键托盘时由宿主按 `Shell_NotifyIconGetRect` 锚点与所在屏工作区自动避让任务栏定位显示，失焦、按 `Esc` 或调 `menuHandle.dismiss()` 自动隐藏（隐藏后释放/回收离屏缓冲避免常驻显存浪费）。
- **窗口任务栏增强与系统全局媒体控制（ADR B1：5）**：
  - `<Window>` 新增三个声明式属性，底层走 `ITaskbarList3` 并监听 `RegisterWindowMessageW(L"TaskbarButtonCreated")` 在首次上任务栏或 Explorer 重启后自动重放：
    - `taskbarProgress?: { state: 'none' | 'indeterminate' | 'normal' | 'paused' | 'error'; value?: number }`（`value` 范围 `[0, 1]`）；
    - `taskbarBadge?: { icon?: string; label?: string } | null`（经 WIC 解码转为 16×16 覆盖 `HICON`）；
    - `taskbarActions?: ReadonlyArray<{ id: string; icon: string; tooltip?: string; enabled?: boolean; dismissOnClick?: boolean; onClick?: () => void }>`（最多 7 项，超限直接报错；宿主内部预占 7 槽位并通过 `THBF_HIDDEN` / `THBF_ENABLED` / `THBF_DISABLED` 动态切换，屏蔽 Win32 `ThumbBarAddButtons` 不可增删限制）。
  - `<MediaSession>` 仅允许挂在 `<App>` 下且同一时刻最多存在一个活跃实例（多挂直接报错）。底层通过纯 Win32/COM ABI（`roapi.h` + `systemmediatransportcontrolsinterop.h` + `windows.media.h`，不引第三方库）绑定 App 隐藏顶层 `HWND`，声明式同步 `playbackStatus`（`'closed' | 'stopped' | 'playing' | 'paused'`）、`title`、`artist`、`album`、`thumbnail`（资产路径或真实磁盘路径）、`canPlay`/`canPause`/`canStop`/`canNext`/`canPrevious` 及对应事件回调（`onPlay`/`onPause`/`onStop`/`onNext`/`onPrevious`）。
- **启动载荷、单实例热唤醒与 Jump List（ADR B1：5）**：
  - `LaunchRequest` 为不可变只读对象 `{ readonly args: readonly string[]; readonly workingDirectory: string }`，宿主在启动挂载前提取命令行参数（不含 exe 自身路径）与当前工作目录，经 `LaunchRequestKey` 注入根组件树（无隐式读取清空副作用）。
  - **单实例控制**：支持由 UI 包清单（`canton-ui.json` 的可选 `singleInstance` 与 `appId` 字段）及开发期环境变量（`CANTON_DEV_SINGLE_INSTANCE` / `CANTON_DEV_APP_ID`）声明；开启后宿主在初始化 QuickJS 前按 AUMID 建立进程互斥体（`CreateMutexW`）与命名管道（`\\.\pipe\canton-single-<hash>`）。若主实例已存活，第二进程将序列化 `LaunchRequest` 经管道投递后调用 `AllowSetForegroundWindow(primaryPid)` 并安静退出（退出码 0）；主实例在 `<App>` 挂载前收到热唤醒时先入队，待 `<App>` 注册 `:onSecondInstance` 后按序派发。
  - **Jump List**：`setJumpList(categories)` 与 `clearJumpList()` 通过 `ICustomDestinationList` 按当前 AUMID 写入自定义分类与任务条目（标题、参数列表、可选图标资产与描述），点击条目重新启动进程并进入统一 `LaunchRequest` 通道；在 `<App>` 挂载前调用直接报错。
- **资产与 `@canton/framework/fs` 文件存储（ADR B1：8）**：
  - 宿主在 `native/src/runtime/` 建立共享后台 I/O 线程池（供 `fs` 与 `net` 共用，退出时有序排空取消）。
  - **应用专属目录透明重定位**（启动期一次只读定案，对 TS 与后续 M7 Native 完全一致）：
    1. 显式重定位根目录（如 `CANTON_DATA_ROOT` / `CANTON_DEV_DATA_ROOT`）→ `<root>/data` 与 `<root>/temp`；
    2. 绿色便携模式（exe 同级存在 `.canton-portable` 标记文件或包清单声明 `portable: true`）→ `<exeDir>/data` 与 `<exeDir>/temp`；
    3. 常规安装态：`dataDir` = `SHGetKnownFolderPath(FOLDERID_LocalAppData)\<appId>`，`tempDir` = `GetTempPath2W()\<appId>`（按需懒创建，不预设空目录）。
  - 用户标准目录一律走 `SHGetKnownFolderPath`，内部全宽字符 UTF-16 并兼容 `\\?\` 长路径；`writeText` / `writeBytes` 开启 `atomic: true` 时先写同目录随机临时文件、`FlushFileBuffers` 刷盘后走 `ReplaceFileW`（目标不存在时 `MoveFileExW(..., MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)`）原子替换。
- **图形能力感知与 WARP 无损内存瘦身（ADR B4：1）**：
  - `<App>` 顶层通过 `GraphicsEnvironmentKey` `provide` 响应式只读 `GraphicsEnvironment`（字段：`backend: 'd3d11'`、`adapterName`、`isSoftwareRenderer`、`hardwareAccelerated`、`isRemoteSession`、`systemTransparency`、`systemAnimations`、`recommendedTier: 'full' | 'reduced'`），底层用 `reactive` 驱动；运行期发生 `DEVICE_REMOVED` 重建切换适配器或隐藏顶层窗收到 `WM_SETTINGCHANGE` 时实时同步更新；允许子树再次 `provide(GraphicsEnvironmentKey, ...)` 覆写。
  - `d3d11::Renderer` 保持完整能力不静默硬砍（守住 WARP 无头回归 100% 确定性基线）；检测到 `adapterInfo.software == true` 时启用无损内存优化：空闲离屏 RT 池按更短帧阈值回收（如 2 帧空闲即释放）、R8 图集从较小初始尺寸（如 `512×512`）按需扩容至上限。
  - `@canton/kyant-glass` 在 `drawBackdrop` / `drawPlainBackdrop` 中通过 `inject(GraphicsEnvironmentKey, undefined)` 感知（仅依赖 `@canton/framework` 与 `@canton/framework/ui` 公开出口）：当 `recommendedTier === 'reduced'` 时跳过离屏背景层录制、多 Pass 模糊与折射/色散着色器，回落为高对比度半透明/实色底与细高光描边（仍保留可选显式覆写能力，且不破坏既有 `shader-effects-glass` 无头回归——无头回归显式以 `full` 档或默认未降级态验真满血效果，另增降级态回归验真）。
- **定时器、取消原语与 `@canton/framework/net`（ADR B4：2–3）**：
  - **定时器**：宿主事件循环维护按到期单调时间排序的最小堆定时队列，结合 `MsgWaitForMultipleObjectsEx` 精确唤醒（零忙等，窗口全关托盘常驻或 0 窗错误屏时同样准确触发），HMR / VM 重载整体撤销。`globalThis` 挂载 `setTimeout`/`clearTimeout`/`setInterval`/`clearInterval`/`queueMicrotask`/`AbortController`/`AbortSignal`；`@canton/framework` 导出 `useTimeout`/`useInterval`（自动 `onScopeDispose`）与 `delay(ms, signal?)`。
  - **网络**：扩展现有 `native/src/runtime/HttpClient.*`（WinHTTP）为完整异步实现（支持全方法、自定义请求头、请求体、总超时、字节上限默认 32MB、重定向默认跟随上限 10 次、Windows 系统代理默认启用、`HttpCancellation` 即时取消），挂载到后台 I/O 线程池；`@canton/framework/net` 导出 `request`、`http.*`（同步 `res.text()/json()/bytes()`）、流式直落盘 `downloadFile`（临时文件原子替换 + 节流进度回调，不经 QuickJS 内存）及结构化 `NetError`（`INVALID_URL`/`NETWORK`/`TIMEOUT`/`ABORTED`/`RESPONSE_TOO_LARGE`/`IO`）。

## 2. 宿主底座升级：App 级隐藏顶层 `HWND`、后台 I/O 线程池与原生定时队列

- [ ] **App 级隐藏顶层 `HWND`（`win32`）**：将 `MessageDispatcher` 演进为（或内置）带 `WS_EX_TOOLWINDOW` 的不可见顶层窗口（禁用 `HWND_MESSAGE`），完整接管跨线程唤醒、`WM_QUERYENDSESSION`/`WM_ENDSESSION`、`WM_FONTCHANGE`、`WM_SETTINGCHANGE`、`TaskbarCreated` 与托盘自定义消息；确保无可见业务窗托盘常驻时零显存、零任务栏项、零 Alt-Tab 项。
- [ ] **宿主后台 I/O 线程池（`runtime`）**：建立轻量的多线程工作池供文件 I/O 与 WinHTTP 请求共享，支持任务取消与退出期有序排空，完成回调经唤醒机制回到 UI Owner 线程安全投递回 QuickJS。
- [ ] **宿主事件循环原生定时队列（`runtime` + `win32`）**：以单调时钟最小堆维护活跃定时项，整合进 `MessageDispatcher` 消息泵（`MsgWaitForMultipleObjectsEx` 按最近到期毫秒休眠唤醒），支持精准单次/周期调度、立即取消及会话重建/HMR 整体清零。

## 3. 图形能力感知与 WARP 无损内存瘦身（ADR B4：1）

- [ ] **原生图形环境采集与动态通知**：在 `win32` 封装系统环境探测（`SM_REMOTESESSION`、`EnableTransparency` 注册表值、`SPI_GETCLIENTAREAANIMATION`），在 `host` 汇总 `d3d11::Renderer::adapter()`（含设备丢失重建后刷新）与系统偏好，经 `runtime` → `quickjs` 推送当前快照与变更事件。
- [ ] **TS `GraphicsEnvironmentKey` 响应式注入**：在 `@canton/framework/ui` 落地 `GraphicsEnvironmentKey` 与响应式只读 `GraphicsEnvironment`（含派生 `recommendedTier`），由 `<App>` 顶层 `provide`，支持子树局部 `provide` 覆写。
- [ ] **WARP 无损内存瘦身**：在 `d3d11::Renderer` 针对 `adapterInfo.software == true` 收紧空闲离屏 RT 池回收阈值，并将 R8 字形/路径图集改为较小初始尺寸按需扩容；确保所有渲染结果逐像素等价，既有 32/32 无头回归零回归。

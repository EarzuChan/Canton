## 0. 已定口径

- **公开导出落点与目录分层**：
  - 新增着色器、滤镜、离屏层、混合模式、色彩矩阵与布局坐标公开 API 统一从 **`@canton/framework/ui`** 导出；Vite `.hlsl` 模块转换所用的内部注册辅助函数从 **`@canton/framework/internal`** 导出，不新增公开子路径。
  - `packages/framework/src` 内部分层归位：`0 values/`（`BlendMode`、`TileMode`、`ColorFilter`、`ColorMatrix`、`CompositingStrategy`、`ShaderBrush`）→ `1 native/protocol.ts`（跨边界协议形状）→ `3 draw/`（`RuntimeEffect`、`RuntimeShader`、`RenderEffect`、`RenderLayer`，及 `DrawScope` / `DrawCacheScope` 扩充）→ `4 layout/`（`LayoutCoordinates`）→ `5 modifier/`（`M.graphicsLayer` 扩充、`M.paint` 升级、`M.onGloballyPositioned`）→ `6 bridge/`（`ModifierLowering` 下发 `Density`、降级描述、管理坐标回调与绘制作用域）。零循环导入由 `tests/runtime/package-layers.test.ts` 守卫。
- **100% 标准 HLSL 着色器契约（SM 5.0，零方言）**：
  - 仅开放像素着色器（`ps_5_0`），默认入口函数名 `main`（允许 `{ entryPoint }` 覆写），约定 `SV_Target` 输出**预乘 Alpha** `float4`。
  - 宿主固定 2D 顶点管线按标准 HLSL 语义向像素着色器提供：
    - `float4 position : SV_Position`：当前目标缓冲设备像素坐标；
    - `float2 fragCoord : TEXCOORD0`：绘制区局部像素坐标，左上 `(0, 0)` 到 `(widthPx, heightPx)`（对齐 SkSL / AGSL 的 `fragCoord`）；
    - `float2 uv : TEXCOORD1`：归一化局部坐标 `(0, 0)` 到 `(1, 1)`。
  - **寄存器槽位避让**：低位槽 **`b0..b11`、`t0..t11`、`s0..s11` 全部留给用户着色器**（用户直接写 `cbuffer Params { ... }`、`Texture2D tex;`、`SamplerState samp;` 默认落入 `b0`/`t0`/`s0`，无需手写 `: register(...)`）；宿主内部矩阵、裁剪掩码与内置常量占用高位槽 `b12..b13`、`t14..t15`、`s12..s15`。
  - **可选虚拟内建头 `<canton.hlsl>`**：构建期与运行期编译器共用同一份内存 `ID3DInclude`，提供可选 `#include <canton.hlsl>`（定义 `CantonInput`、`cbuffer Canton : register(b12)` 含 `float2 cantonResolution; float2 cantonInvResolution;` 以及预置采样器 `cantonLinearClamp` / `cantonLinearWrap` / `cantonLinearMirror` / `cantonLinearDecal` / `cantonPointClamp`）；不写 `#include` 的纯裸标准 HLSL 同样合法。
- **`RuntimeEffect`、`RuntimeShader`、`D3DReflect` 自动对齐与双轨编译**：
  - **`RuntimeEffect`（不可变可缓存的已编译程序）**：
    1. 静态 `.hlsl` 文件导入：`import effect from './foo.hlsl'`，默认导出即为 `RuntimeEffect`（在 `types/canton-globals.d.ts` 及公开类型中补齐 `*.hlsl` 模块声明）；
    2. 运行期动态字符串编译：`createRuntimeEffect(hlslSource: string, options?: { entryPoint?: string; debugName?: string }): RuntimeEffect`。
  - **`RuntimeShader`（绑定参数的着色器实例）**：`createRuntimeShader(effect)`（在组件 setup 响应式作用域或 `drawWithCache` 构建作用域内自动登记销毁释放，也支持手动 `dispose()`）：
    - `setFloat(name, ...values)` / `setFloat(name, valuesArray)`：支持标量、`float2..4`、矩阵与定长数组；
    - `setInt(name, ...values)` / `setInt(name, valuesArray)`：支持 `int` / `uint` / `bool` 标量、向量与数组；
    - `setColor(name, color)`：`.cta` 契约校验 `'color'` 单位，原生自动将 `0xAARRGGBB` 转为预乘 `float4(r*a, g*a, b*a, a)` 写入目标 `float4` 字段；
    - `setPainter(name, painter | null, options?: { tileModeX?: TileMode; tileModeY?: TileMode; filter?: 'linear' | 'nearest' })`：绑定任意 `Painter`（位图、SVG、`PixelBuffer`、`Filmstrip`）作为子纹理输入，并为对应采样器槽绑定匹配的 `ID3D11SamplerState`。
  - **自动反射与零重编更新**：无论来自运行期 `D3DCompile` 还是预编译 DXBC，原生统一通过 `D3DReflect`（`ID3D11ShaderReflection`）解析 `cbuffer` 各变量精确 `StartOffset`、`Size`、行列类型与纹理/采样器绑定槽，TS 侧免手算 16 字节对齐（字段类型或分量数不符直接报错）。`RuntimeShader` 内部持有版本号 `shallowRef`，改 uniform 仅更新常量缓冲快照并触发重绘，不重编着色器。
  - **Dev 保状态热替换与报错容错**：Live 模式下 `@canton/vite-plugin` 将 `.hlsl` 编译为 `import.meta.hot.accept` 自接受模块。修改 `.hlsl` 保存后原地热替换底层 `ID3D11PixelShader` 与反射布局，不卸载 `.cta` 实例、保留已有 `RuntimeShader` 已写入的同名 uniform；编译失败时输出带文件名与行号的诊断并弹 Dev Toast，**保留上一版有效着色器继续运行**，不进错误屏。
  - **Dist 预编译 DXBC（`koffi` 直调系统 `d3dcompiler_47.dll`）与设备恢复**：
    - `@canton/framework` 引入 `koffi: "2.14.1"`（与 `cli` 同版本）；`@canton/vite-plugin` 在 `vite build` 期间经 `koffi` 直接调用 Windows 系统自带 `d3dcompiler_47.dll`（`D3DCompile`，`ps_5_0` + `/O3`）将静态 `.hlsl` 预编译为 `assets/<name>-<hash>.dxbc` 并写入 `canton-ui.json`（含 SHA-256），同时覆盖 `js` 与 `bytecode` 两种 Dist 包及无头回归夹具，不新增额外 `.exe` 制品；
    - 宿主运行期按需加载系统 `d3dcompiler_47.dll`：预编译 `.dxbc` 直接走 `CreatePixelShader` + `D3DReflect` 零编译冷启动，动态字符串 `createRuntimeEffect` 走运行期 `D3DCompile`；遇到 `DEVICE_REMOVED` / `DEVICE_RESET` 时从内存已缓存的 DXBC 字节码自动重建全部用户像素着色器与离屏资源。
- **对齐 Compose 的枚举、色彩矩阵与滤镜单位口径**：
  - **`BlendMode`（大驼峰，全量 29 种）**：导出冻结常量对象与同名字符串字面量联合类型，严格对齐 Compose：`Clear`、`Src`、`Dst`、`SrcOver`、`DstOver`、`SrcIn`、`DstIn`、`SrcOut`、`DstOut`、`SrcAtop`、`DstAtop`、`Xor`、`Plus`、`Modulate`、`Screen`、`Overlay`、`Darken`、`Lighten`、`ColorDodge`、`ColorBurn`、`HardLight`、`SoftLight`、`Difference`、`Exclusion`、`Multiply`、`Hue`、`Saturation`、`Color`、`Luminosity`。前 15 种走 D3D11 硬件 `ID3D11BlendState`；后 14 种按当前图元紧缩裁剪矩形做 `CopySubresourceRegion` 局部拷出 + 内置混合像素着色器精确合成。
  - **`TileMode`（大驼峰，4 种）**：`Clamp`、`Repeated`、`Mirror`、`Decal`。
  - **`CompositingStrategy`（大驼峰，3 种）**：`Auto`、`Offscreen`、`ModulateAlpha`。
  - **`ColorMatrix` 与 `ColorFilter`（对齐 Compose `[0..255]` 偏置量纲）**：
    - `ColorMatrix` 采用 20 浮点数 `4×5` 行主序矩阵，第 5 列平移偏置（下标 `4, 9, 14, 19`）严格对齐 Compose 的 **`[0..255]` 量纲**（底层同 `SkiaColorFilter` 除以 `255` 后送入着色器），提供 `reset`、`set`、`setToSaturation`、`setToScale`、`setToRotateRed`、`setToRotateGreen`、`setToRotateBlue`、`multiply` 等方法；
    - `ColorFilter` 提供 `ColorFilter.tint(color, blendMode = BlendMode.SrcIn)`、`ColorFilter.colorMatrix(colorMatrix)`、`ColorFilter.lighting(multiply, add)`（`.cta` 契约校验 `'color'` 参数；`M.paint` 同时兼容现有 `{ tint }` 并支持传入 `ColorFilter`）。
  - **`RenderEffect`（严格对齐 Compose 只收 `.px`）**：
    - `RenderEffect.blur(radiusX, radiusY = radiusX, edgeTreatment = TileMode.Clamp, input?)`（长度参数契约为 `'px'`；GPU 两 Pass 可分离高斯模糊，`radius <= 0` 自动短路直通）；
    - `RenderEffect.offset(x, y, input?)`（长度参数契约为 `'px'`）；
    - `RenderEffect.colorFilter(colorFilter, input?)`；
    - `RenderEffect.shader(runtimeShader, uniformShaderName, input?)`（将前序离屏纹理绑定到 `runtimeShader` 的 `uniformShaderName` 纹理槽，同时保留该着色器自身的其它 uniform 与附加 `Painter` 纹理）；
    - `RenderEffect.chain(first, second, ...rest)` 与实例方法 `effect.then(next)`（按流水线执行先后顺序串联：`first` 输出作为 `second` 输入，底层经 D3D11 离屏 RT 池做 Ping-Pong 复用）。
- **着色器笔刷、离屏层、全局坐标与组透明度**：
  - **`shaderBrush(shader)`**：加入 `Brush` 联合类型，通用于 `M.background`、`M.border` 及 `DrawScope` 的形状/线段/路径填充与描边。轴对齐无裁剪纯填充矩形直跑用户 PS 单 Pass；带圆角、内/中线描边、线段端点、`Path` 覆盖率掩码或非矩形裁剪时，在紧缩包围盒的池化临时 RT 上跑用户 PS 后交 `Quad.hlsl` 乘覆盖率与裁剪掩码，保持一致抗锯齿品质。
  - **`RenderLayer` 与 `DrawScope` / `DrawCacheScope` 扩充**：
    - `createRenderLayer()` 创建离屏层句柄，支持属性 `alpha`、`blendMode`、`colorFilter`、`renderEffect`、`clip`、`shape`、`translationX` / `translationY`（`px`）、`scaleX` / `scaleY`、`rotationZ`、`transformOrigin`、`topLeft`（`px`）、`compositingStrategy` 及只读 `size`、`isReleased` / `isDisposed`、`dispose()`；
    - `DrawScope` 补齐只读 `density: Density`、`recordLayer(layer, [size], draw)`（在 `M.drawWithContent` 内调 `drawContent()` 时直接关联该节点的 C++ 原生保留子片段树，子项滚动/动画时无需重跑父节点 JS 即可更新层内容并联动重绘脏区）、`drawLayer(layer)`、分角圆角 / `Shape` 轮廓绘制与裁剪（`drawOutline` / `clipOutline` 或四角 `corners` 重载）、`withTransform` 通用 2D 仿射矩阵 `{ a, b, c, d, tx?, ty? }`，以及各绘制命令的 `blendMode` 与 `colorFilter`；
    - `M.drawWithCache(scope => ...)` 的 `scope` 扩充为 `{ size, density, onDispose }`，构建期内调用的 `createRenderLayer()` / `createRuntimeShader()` 自动随节点 `DrawInstance` 缓存重算或卸载销毁；
    - C++ 管线内置 `RenderLayer` 访问栈有向环检测，录制层内直接或间接 `drawLayer` 自身时立即抛出明确中文诊断，杜绝递归死锁或 D3D11 同纹理同时绑定 RTV/SRV。
  - **`M.onGloballyPositioned` 与 `LayoutCoordinates`**：
    - `LayoutCoordinates`（像素 `'px'` 契约）提供 `size`、`isAttached`、`positionInWindow`、`positionInParent`、`boundsInParent`、`boundsInWindow({ clipBounds? })`、`localToWindow`、`windowToLocal`、`localPositionOf(source, relativeToSource?)`、`localBoundingBoxOf(source, { clipBounds? })`；跨窗口或已卸载节点互算直接报错；
    - 派发时机：在 `SceneFramePipeline::prepare` 中紧接 **`layout_.place()` 完成之后、`preparation.draw()` 执行之前** 按树自顶向下派发几何变更（首次挂载必派发，几何未变不重发，候选回滚时随 `LayoutTree` 日志同步回滚已派发几何），确保回调更新的偏移量在当帧 `DrawScope` / `RenderLayer` / `RuntimeShader` 中**零一帧滞后**立即生效。
  - **组透明度与 `M.graphicsLayer` 补全（承接 M3 移交）**：

# 008 描边口径与 Lazy 项动画放在绘制层

日期 2026-11-22。

> 本文补齐了 [batch2 ADR 003](./3：槽位参数只在类型层面、父布局数据按种类校验.md) 里移交出去的 `animateItem`。

## 背景

旧实现的形状描边口径是“矩形向内、圆角与椭圆以轮廓为中线”，同一个 `StrokeRect` 指令同时服务 `border` 修饰器和 Canvas 的形状描边。Lazy 的 `animateItem` 要做位移、淡入、淡出，且已移除的项要留到动画结束。

## 决定

- **描边对齐 Compose，分两类**：`border` 修饰器（及诊断框）对所有形状向内；Canvas 的 `drawRect`、`drawRoundRect`、`drawOval` 描边对所有形状以轮廓为中线，与 `drawPath` 一致，直角矩形的外角是尖角。绘制指令上带一个“描边向内”的标记区分两类，绘制边界的外扩量随之对齐。
- **`animateItem` 在绘制片段这一层做**，不动布局与事务：Lazy 容器构建绘制片段时按项的 key 比较本次与上次，位置变了给该项的片段加一个衰减到 0 的偏移；数据集里新出现的 key 包一层带透明度的片段淡入；从数据集消失的 key 把上次的片段作为残影留在容器里淡出。状态在 `LazyLayoutState`，进行中的项动画计入活动动画并标脏容器。坐标扣除布局为保持锚点而做的滚动补偿，滚动和锚点修正都不算位移；滚进滚出视口不触发淡入淡出。
- 修饰器写在项内容的根节点上，整项一起动；用在别处报错。网格项交付只有 `animateItem` 的 Handle。

## 为什么不选别的

- **描边全部向内**：Canvas 的路径描边只能以中线为准，形状描边向内就和路径不一致，同一条轮廓用 `drawRect` 和 `drawPath` 画出来粗细位置不同。
- **在布局里做项动画**（放置时插值）：每帧都要重新放置并重建命中，还会把动画中的位置写进滚动快照和可见项元数据，脚本读到的是中间值。
- **残影留在场景树里**：已移除项的节点要延迟退休，和 key 迁移、材料化缓存、事务回滚纠缠在一起。

## 代价

- 命中区域不跟随项动画，动画中途点到的是目标位置。
- 只有上次画过的项才做位移；滚进视口同时又因数据变化挪了位置的项直接出现在新位置。
- 项内多层半透明内容淡入淡出时按元素分别乘透明度，重叠处会比整体透明略深（与现有 `alpha` 修饰器一致，组透明度属 M5 的 `RenderLayer`）。
